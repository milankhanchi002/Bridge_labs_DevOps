                      LINUX SYSTEM ADMINISTRATION NOTES
                 MODULE: STORAGE PARTITIONING & FILESYSTEMS
================================================================================

1. STORAGE LIFE CYCLE STAGES
--------------------------------------------------------------------------------
Stage 1: Raw Disk Detection   -> System sees disk device (e.g., /dev/sdb).
Stage 2: Partitioning         -> Divide disk into logical parts (MBR or GPT).
Stage 3: Formatting           -> Create a Filesystem (ext4, xfs) on partition.
Stage 4: Mounting             -> Attach partition to a Directory Mount Point.
Stage 5: Persistence          -> Add entry in /etc/fstab for boot survival.


2. KEY TERMINOLOGY
--------------------------------------------------------------------------------
* Raw Disk Name    : /dev/sda (SATA/SCSI) or /dev/nvme0n1 (NVMe SSD)
* Partition Name   : /dev/sda1 or /dev/nvme0n1p1
* MBR Limits       : Max 2 TB disk size, Max 4 Primary partitions.
* GPT Limits       : > 2 TB disk size support, Max 128 partitions.
* Filesystem Types : ext4 (Standard/Stable), xfs (Enterprise Default/High-IO).

================================================================================
                      LINUX SYSTEM ADMINISTRATION NOTES
                 MODULE: DISK PARTITIONING TOOL (fdisk)
================================================================================

1. COMMAND PURPOSE & SYNTAX
--------------------------------------------------------------------------------
Command Name : fdisk (Fixed Disk / Format Disk)
Binary Path  : /sbin/fdisk or /usr/sbin/fdisk
Package      : util-linux

Syntax:
  sudo fdisk -l               : Lists all disks, partitions, and sizes.
  sudo fdisk -l /dev/sdb      : Lists details for a specific disk (/dev/sdb).
  sudo fdisk /dev/sdb         : Opens interactive mode to manage /dev/sdb.


2. INTERACTIVE SUB-COMMAND CHEAT SHEET
--------------------------------------------------------------------------------
Sub-Command   Action
--------------------------------------------------------------------------------
  m           Displays the help menu with all options.
  p           Prints/Displays the current partition table.
  n           Creates a NEW partition.
  d           DELETES a partition.
  t           Changes partition System ID / Type (e.g., LVM, Swap).
  l           Lists all available partition type codes.
  w           WRITES changes to disk and exits (Permanent Action).
  q           QUITS without saving changes (Safe Cancel).


3. STEP-BY-STEP WORKFLOW TO CREATE A PARTITION
--------------------------------------------------------------------------------
Step 1: Open disk        -> `sudo fdisk /dev/sdb`
Step 2: Start new part   -> Type `n`
Step 3: Select type      -> Type `p` (Primary)
Step 4: Select number    -> Press ENTER for default (1)
Step 5: Set start sector -> Press ENTER for default (2048)
Step 6: Set size         -> Type `+5G` (Allocates 5 Gigabytes)
Step 7: Confirm changes  -> Type `p`
Step 8: Save & Apply     -> Type `w`
Step 9: Kernel re-read   -> Execute `sudo partprobe /dev/sdb`
================================================================================
                                END OF NOTES

================================================================================
                      LINUX SYSTEM ADMINISTRATION NOTES
                 MODULE: LARGE DISK MANAGEMENT (parted)
================================================================================

1. COMMAND PURPOSE & OVERVIEW
--------------------------------------------------------------------------------
Command Name : parted (Partition Editor)
Binary Path  : /sbin/parted or /usr/sbin/parted
Package      : parted

Why use parted over fdisk?
- Full native support for GPT (GUID Partition Table) and disks > 2TB.
- Supports non-interactive command-line execution for automation/scripting.
- Supports live partition resizing and alignment verification.
- CRITICAL: Changes in `parted` are applied IMMEDIATELY to disk.


2. ESSENTIAL CLI COMMAND VARIATIONS
--------------------------------------------------------------------------------
List all system disks & partitions  : sudo parted -l
Print specific disk layout          : sudo parted /dev/sdb print
Create GPT label non-interactively  : sudo parted /dev/sdb mklabel gpt
Create 500GB partition non-stop    : sudo parted /dev/sdb mkpart primary ext4 1MiB 500GiB


3. INTERACTIVE STEP-BY-STEP WORKFLOW
--------------------------------------------------------------------------------
Step 1: Open interactive shell       -> sudo parted /dev/sdb
Step 2: Label disk as GPT            -> (parted) mklabel gpt
Step 3: Set default size units       -> (parted) unit GB
Step 4: Create new partition         -> (parted) mkpart primary ext4 0% 1000GB
Step 5: Verify alignment             -> (parted) align-check optimal 1
Step 6: Confirm partition creation   -> (parted) print
Step 7: Quit session                 -> (parted) quit

Step 8: Notify Kernel of changes     -> sudo partprobe /dev/sdb
================================================================================
                                END OF NOTES
================================================================================















================================================================================
                      LINUX SYSTEM ADMINISTRATION NOTES
               MODULE: FORMATTING PARTITIONS (mkfs & FILESYSTEMS)
================================================================================

1. COMMAND PURPOSE & OVERVIEW
--------------------------------------------------------------------------------
Command Name : mkfs (Make Filesystem)
Binary Path  : /sbin/mkfs, /sbin/mkfs.ext4, /sbin/mkfs.xfs
Package      : e2fsprogs (for ext4), xfsprogs (for xfs)

Primary Use:
- Builds a Linux filesystem (ext4, xfs, btrfs, vfat) on a storage partition.
- Prepares raw partition space so it can be mounted into the directory tree.


2. EXT4 vs XFS COMPARISON MATRIX
--------------------------------------------------------------------------------
Feature               ext4                       xfs
--------------------------------------------------------------------------------
Default On          : Ubuntu / Debian            RHEL / CentOS / Rocky Linux
Max File Size       : 16 Terabytes               8 Exabytes
Max Filesystem Size : 1 Petabyte                 8 Exabytes
Shrink Capability   : Supported (resize2fs)      NOT Supported
Best For            : General Apps / OS Drives   Large Files & High IO Databases


3. PRODUCTION COMMAND REFERENCE
--------------------------------------------------------------------------------
1. Format partition with ext4:
   $ sudo mkfs.ext4 /dev/sdb1
   OR
   $ sudo mkfs -t ext4 /dev/sdb1

2. Format partition with xfs:
   $ sudo mkfs.xfs /dev/sdb2
   OR
   $ sudo mkfs -t xfs /dev/sdb2

3. Force format an existing partition with xfs:
   $ sudo mkfs.xfs -f /dev/sdb2

4. Format and assign a filesystem label:
   $ sudo mkfs.ext4 -L "WEB_LOGS" /dev/sdb1
   $ sudo mkfs.xfs -L "DB_DATA" /dev/sdb2


4. POST-FORMAT VERIFICATION COMMANDS
--------------------------------------------------------------------------------
Inspect UUID and Filesystem type     : sudo blkid /dev/sdb1
Display full block device tree       : lsblk -f
Inspect ext4 partition details       : sudo tune2fs -l /dev/sdb1
Inspect xfs partition details        : sudo xfs_info /dev/sdb2
================================================================================
                                END OF NOTES

================================================================================
                      LINUX SYSTEM ADMINISTRATION NOTES
             MODULE: MOUNTING & PERSISTENT STORAGE (/etc/fstab)
================================================================================

1. COMMANDS & CONCEPTS
--------------------------------------------------------------------------------
mount   : Attaches a filesystem to the directory hierarchy.
umount  : Detaches a filesystem from the directory hierarchy.
blkid   : Displays Block device UUIDs and Filesystem types.
df -hT  : Displays mounted filesystems with disk space usage and types.


2. TEMPORARY MOUNT WORKFLOW
--------------------------------------------------------------------------------
Step 1: Create mount point  -> sudo mkdir -p /mnt/data
Step 2: Attach partition    -> sudo mount /dev/sdb1 /mnt/data
Step 3: Verify mount        -> df -hT /mnt/data
Step 4: Unmount cleanly     -> sudo umount /mnt/data


3. PERMANENT MOUNTING SETUP (/etc/fstab)
--------------------------------------------------------------------------------
Step 1: Find Partition UUID:
  $ sudo blkid /dev/sdb1
  Output: /dev/sdb1: UUID="9f8e7d6c-5b4a-3f2e-1d0c-9b8a7f6e5d4c" TYPE="ext4"

Step 2: Append line to /etc/fstab (`sudo nano /etc/fstab`):
  # <UUID/Device>                           <Mount Point>  <Type> <Options>  <Dump> <Pass>
  UUID=9f8e7d6c-5b4a-3f2e-1d0c-9b8a7f6e5d4c /mnt/data      ext4   defaults   0      2

Step 3: Test syntax (CRITICAL):
  $ sudo mount -a
  (If no errors are displayed, the configuration is safe for reboot).


4. /etc/fstab FIELD EXPLANATIONS
--------------------------------------------------------------------------------
Field 1: Specifier     -> UUID=... or /dev/sdb1
Field 2: Mount Point   -> Directory path where files will be accessed
Field 3: Type          -> ext4, xfs, nfs, etc.
Field 4: Options       -> defaults (includes rw, suid, dev, exec, auto)
Field 5: Dump          -> 0 (Disable dump backup)
Field 6: Pass (FSCK)   -> 1 for Root (/), 2 for other data drives, 0 to skip check
================================================================================
                                END OF NOTES

================================================================================
                      LINUX SYSTEM ADMINISTRATION NOTES
                 MODULE: SWAP SPACE MANAGEMENT & TUNING
================================================================================

1. COMMANDS CHEAT SHEET
--------------------------------------------------------------------------------
mkswap   : Formats a partition or file into Linux Swap area.
swapon   : Activates swap space (makes it usable by Kernel).
swapoff  : Deactivates active swap space.
free -h  : Displays total, used, and free RAM & Swap space.
swapon -s: Summarizes active swap devices/files.


2. SWAP FILE CREATION WORKFLOW (STEP-BY-STEP)
--------------------------------------------------------------------------------
Step 1: Allocate space    -> sudo fallocate -l 2G /swapfile
Step 2: Restrict access   -> sudo chmod 600 /swapfile
Step 3: Format as Swap    -> sudo mkswap /swapfile
Step 4: Enable Swap       -> sudo swapon /swapfile
Step 5: Verify Activation -> free -h  OR  sudo swapon --show


3. PERSISTENT MOUNTING (/etc/fstab)
--------------------------------------------------------------------------------
File Path: /etc/fstab

For Swap File:
  /swapfile       none    swap    defaults    0    0

For Swap Partition:
  /dev/sdb2       none    swap    defaults    0    0
  OR
  UUID=a1b2c3...  none    swap    defaults    0    0


4. SWAP REMOVAL WORKFLOW
--------------------------------------------------------------------------------
Step 1: Deactivate       -> sudo swapoff /swapfile
Step 2: Remove Entry     -> Remove line from /etc/fstab
Step 3: Delete File      -> sudo rm -f /swapfile


5. KERNEL SWAPPINESS TUNING
--------------------------------------------------------------------------------
Swappiness Range : 0 to 100 (Default: 60)
Low Swappiness   : Keeps data in physical RAM as long as possible (Fast).
High Swappiness  : Aggressively moves idle processes to Swap (Frees RAM).

Commands:
  Check Current Value : cat /proc/sys/vm/swappiness
  Temporary Change    : sudo sysctl vm.swappiness=10
  Permanent Change    : Add `vm.swappiness=10` to /etc/sysctl.conf
================================================================================
                                END OF NOTES
