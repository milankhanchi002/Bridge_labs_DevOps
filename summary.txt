8. NETWORK SECURITY GROUPS – COMPLETED

Automatically created VM NSGs were deleted.

Final design uses subnet-level NSGs.

Subnet -> NSG
NIC -> ASG

NSG-WEB

Associated with:
snet-web-public-1

Inbound rules:
Internet -> asg-web : TCP 80 -> ALLOW
Your IP -> asg-web : TCP 22 -> ALLOW

Outbound rule:
asg-web -> asg-app : TCP 8000 -> ALLOW

8000 is currently assumed as Django internal application port.
It can be edited later if application uses another port.

NSG-APP

Associated with:
snet-app-private-1

Inbound:
asg-web -> asg-app : TCP 8000 -> ALLOW
asg-web -> asg-app : TCP 22 -> ALLOW
Internet -> asg-app : ANY -> DENY (priority 400)

Outbound:
asg-app -> asg-db : TCP 3306 -> ALLOW

NSG-DB

Associated with:
snet-db-private-2

Inbound:
asg-app -> asg-db : TCP 3306 -> ALLOW
asg-web -> asg-db : TCP 22 -> ALLOW
asg-web -> asg-db : TCP 3306 -> DENY
Internet -> asg-db : ANY -> DENY

Reason Web -> DB TCP 22 is allowed:
Web is being used as temporary jump host for administration.

Reason Web -> DB TCP 3306 is denied:
Web must not directly access MySQL.
Only App tier can access MySQL.

Important concept:
NSG rules are port/protocol-specific.

Therefore:
asg-web -> asg-db : 22 = ALLOW
asg-web -> asg-db : 3306 = DENY

These are not contradictory.
