[ ] MODULE 1: LINUX SYSTEM ARCHITECTURE & LAYERS
--------------------------------------------------------------------------------
    [ ] 1.1 User Space
        - Applications, Daemons (systemd, sshd), Shell (bash, zsh)
        - C Library (glibc): Abstraction layer converting system calls

    [ ] 1.2 System Call Interface (SCI)
        - Boundary between User Mode (Ring 3) and Kernel Mode (Ring 0)
        - Key Assembly Instructions: `syscall` and `sysretq`
        - Kernel entry function: `entry_SYSCALL_64`
        - Mechanism: `swapgs` instruction, `IA32_LSTAR` MSR register, `pt_regs` frame

    [ ] 1.3 Kernel Space Subsystems
        - Process Scheduler: Completely Fair Scheduler (CFS), `task_struct`
        - Memory Management: Virtual memory, Paging (4KB), Page Faults, MMU
        - Virtual File System (VFS): Abstract layer, Inodes, Dentries
        - Network Stack: TCP/IP stack, Socket layer, `iptables`/`nftables`
        - Device Drivers: Dynamically loadable kernel modules (.ko files)

    [ ] 1.4 Hardware Layer
        - CPU Ring 0 vs Ring 3 execution privilege levels
