PHASE 2 — Azure CLI Command Structure & Resource Groups
Goal

Understand the grammar/pattern of Azure CLI commands, rather than memorizing individual commands.

Concepts
az command hierarchy
Command groups and subcommands
create / list / show / update / delete
Parameters and flags
Required vs optional parameters
Resource names vs resource IDs
Subscription and resource-group targeting
CLI help at different levels
Output formats: table, json, tsv
Exit codes and basic command success/failure
Hands-on

Start with Resource Groups because you already understand them from the Portal:

az group create
az group list
az group show
az group exists
az group delete

Then learn:

az group --help
az group create --help
Practical exercise

Create a small practice resource group, inspect it, modify its tags, list it, and finally delete it.

You'll learn the complete lifecycle:

CREATE
  ↓
SHOW
  ↓
LIST
  ↓
UPDATE
  ↓
DELETE
PHASE 3 — Querying Azure with CLI

This is where CLI becomes much more powerful.

Concepts
JSON output
-o table
-o json
-o tsv
--query
JMESPath basics
Filtering
Selecting specific properties
Extracting values for scripts
Hands-on

Start with:

az group list -o table

Then:

az group list -o json

Then begin querying:

az group list --query "[].name" -o table

You'll learn to go from:

Azure returns lots of information
            ↓
       --query
            ↓
Only the information I need

This is very important for DevOps scripting.

PHASE 9 — CLI → Infrastructure as Code

This is the bridge toward the next major DevOps skill.

You'll understand why repeatedly doing:

az network vnet create ...
az network subnet create ...
az network nsg create ...
az vm create ...

is still not ideal for large infrastructure.

Then move toward:

Imperative
   ↓
"Create this"
   ↓
Azure CLI

to:

Declarative
   ↓
"This is what my infrastructure should look like"
   ↓
Bicep / Terraform

Since you've already touched Bicep, this will make much more sense after CLI.

What I recommend right now

Don't jump to networking yet.

Start Phase 2 with just:

az group show
az group exists
az group delete

We'll take each command one at a time and for each one I'll explain:

What → Why → Syntax → Parameters → What happens behind the scenes → Hands-on → Verify → Cleanup

That approach will prevent CLI from becoming another command-memorization exercise.
