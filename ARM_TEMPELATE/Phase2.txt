1. $schema
Example:
"$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#"
This tells tools:
"This JSON follows the ARM deployment template schema."
Think of it like the rulebook/structure definition for the JSON.
You normally don't need to modify it.




2.   "contentVersion": "1.0.0.0"
This is simply the version of your template.

7.Why not just use parameters for everything?
Because parameters represent things you expect to vary.
Suppose:
Environment = Development
Location = East Asia
These might be parameters.

But suppose your naming convention is:
chatapp-dev-vnet
chatapp-dev-nsg
chatapp-dev-vm
You could construct these names using variables/functions rather than asking the user to enter every 
single name.
This keeps the deployment consistent.
